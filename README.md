# 차곡여행 · Travel Agent

**ChatGPT에서 추천받고, 앱에서 여행 계획을 보관·편집합니다.** 항공권 → 호텔 → 일정 → 일정에 따른 식당 순서로 여행을 준비합니다.

## 비용과 연결 방식

- 이 앱은 OpenAI API를 호출하지 않습니다. API 키·API 결제·추가 크레딧이 필요하지 않습니다. 키가 환경에 남아 있어도 사용하지 않습니다.
- AI 추천은 사용자가 ChatGPT 웹/앱에서 직접 받습니다. 보유한 ChatGPT 요금제의 기능·사용 한도가 적용됩니다. 구독이 무제한 이용을 뜻하지는 않습니다.
- ChatGPT 구독을 외부 앱의 API 인증으로 사용하는 연결 기능은 제공하지 않습니다. 앱에서 요청문을 복사하고 ChatGPT에 붙여넣는 방식입니다.
- 앱은 ChatGPT 로그인·구독 정보·쿠키를 요구하지 않습니다. ChatGPT 열기 링크만으로 여행 정보가 전송되지는 않습니다.

## 실행

Python 3.12 이상과 [uv](https://docs.astral.sh/uv/)가 필요합니다.

```bash
cd /workspace/Travel-Agent
export UV_CACHE_DIR=/workspace/travel-agent-tools/cache
uv sync --frozen --extra dev
.venv/bin/python -m travel_agent.server --port 8000
```

기본 실행은 이 컴퓨터에서만 접근 가능한 포트 8000에 바인딩합니다. 클라우드에서는 내부 HTTP 요청으로 검증합니다. 공개 배포용 인증·TLS·다중 사용자 권한 관리는 포함하지 않습니다.

선택 설정은 `TRAVEL_AGENT_DB`(SQLite 데이터 경로)뿐이며 기본값은 `.data/trips.sqlite3`입니다. `.env` 파일을 자동으로 읽지는 않습니다. 기존 데이터베이스는 그대로 사용할 수 있습니다.

## 사용 순서

1. **항공권**: 요청 칸에 출발지·목적지·날짜·인원·예산을 입력하고 **ChatGPT 요청문 만들기 → 요청문 복사 → ChatGPT 열기**를 누릅니다. ChatGPT에 붙여넣어 후보를 비교한 뒤, 선택한 항공편을 앱 왼쪽에서 확정합니다.
2. **호텔**: 확정 항공 정보가 포함된 요청문으로 숙소를 추천받고, 선택한 호텔을 앱에서 확정합니다.
3. **일정**: 관심사·여행 속도·수정사항을 적어 요청문을 만듭니다. ChatGPT는 설명과 함께 최종 일정 전체를 JSON 코드 블록으로 제공하도록 요청받습니다. 그 코드 블록을 **ChatGPT 일정 가져오기**에 붙여넣어 **일정 미리보기 → 확인한 일정으로 교체**를 누릅니다. 원하면 수동으로 추가·수정·삭제해도 됩니다.
4. **식당**: 일정의 **이 일정 근처 식당**을 누르면 현재 시간·위치·전후 일정이 요청문에 반영됩니다. ChatGPT에서 추천받은 식당을 일정의 장소·메모에 저장하세요.

매번 최신 여행 상태를 요청문에 포함하므로 ChatGPT에서 새 대화를 열어도 계획을 이어갈 수 있습니다. ChatGPT를 여행 전용으로 설정할 수 있는 지침은 [CHATGPT_AGENT.md](CHATGPT_AGENT.md)에 있습니다.

## 일정과 저장 규칙

- 항공 정보가 바뀌면 호텔과 일정, 호텔 정보가 바뀌면 일정이 초기화됩니다. 화면에서 확인을 받습니다. 동일한 정보를 다시 저장하면 유지합니다.
- 개별 일정 수정·삭제와 일정 가져오기는 확정 항공·호텔을 유지합니다.
- 일정 가져오기는 **기존 일정 전체 교체**입니다. 미리보기는 저장하지 않으며 사용자가 확인해야 적용됩니다.
- 잘못된 JSON, 중복 ID, 겹치는 시간, 체류 범위 밖의 일정은 거부합니다. 모든 날짜·시간은 목적지 현지 기준입니다.
- 여러 창에서 수정하면 버전 충돌을 감지합니다. 요청문·미리보기 생성 후 여행을 수정하면 이전 결과를 숨기고 다시 만들도록 합니다.
- 저장 버튼으로 확정한 내용만 저장됩니다. 입력 중인 내용은 자동 저장하지 않습니다.
- 서버는 SQLite에 저장하고 브라우저는 마지막 여행 ID를 기억합니다. 새 여행을 만들어도 이전 데이터는 서버에 남습니다. 여행 목록·계정 동기화는 아직 없습니다.

## 검증

```bash
.venv/bin/python -m pytest -q
.venv/bin/ruff check .
node --check travel_agent/static/app.js  # Node.js가 있는 경우
```

도메인·실제 HTTP·SQLite·동시 수정·네트워크 없는 요청문 생성·일정 미리보기와 명시적 적용을 테스트합니다. ChatGPT 대화 자체는 사용자가 진행하며 테스트에서 구독 계정에 로그인하거나 유료 API를 호출하지 않습니다.

## 구성과 API

- `domain.py`: 단계별 여행 상태·입력 검증
- `agent.py`: 로컬 요청문 생성·가져올 일정 검증 (외부 호출 없음)
- `store.py`: SQLite 저장·버전 충돌 감지
- `server.py`, `static/`: HTTP API·한국어 반응형 UI

주요 경로:

- `POST /api/trips`, `GET /api/trips/{id}`: 생성·조회
- `POST /api/trips/{id}/flight`, `/hotel`, `/activities`: `{ "version": 0, "data": ... }`
- `POST /api/trips/{id}/prompt`: `{ "version": 0, "stage": "flight", "message": "..." }`
- `POST /api/trips/{id}/import-preview`: `{ "version": 2, "text": "일정 JSON" }`
- `GET /api/health`: `mode: chatgpt_manual`, `api_calls_enabled: false`

이전 유료 AI 호출 경로 `/advice`는 제거했습니다. OpenAI SDK도 의존성에서 제거했습니다.

## 범위

항공·호텔·식당 후보는 ChatGPT에서 제공되는 검색 기능으로 조사합니다. 최신 정보를 확인할 수 없는 경우 확인 불가로 표시하도록 요청합니다. 실시간 예약 재고 API와 결제·예약 기능은 없습니다. 가격·영업시간·예약 조건은 공식 사이트에서 최종 확인하세요.

한 목적지·한 숙소를 기준으로 합니다. 여러 도시·숙소, 당일치기, 시간대 자동 변환·공항 이동 시간 자동 계산은 후속 확장 대상입니다. 요청문을 ChatGPT에 붙여넣으면 그 내용이 ChatGPT에 전달되므로 여권번호·결제정보를 넣을 필요는 없습니다.
